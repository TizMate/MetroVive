# Proyecto StadiumAI

## Descripción

StadiumAI es una plataforma inteligente para mejorar la experiencia de los asistentes y optimizar la operación del Estadio Metropolitano Roberto Meléndez mediante Inteligencia Artificial.

## Objetivo

Reducir tiempos de espera, mejorar la orientación dentro del estadio y optimizar la logística de atención durante eventos masivos.

## Módulos

### Orientación Inteligente

Permite a los asistentes encontrar fácilmente su asiento, baños, tiendas, primeros auxilios y salidas mediante un agente conversacional.

### Servicio desde el Asiento

Permite solicitar alimentos, bebidas o asistencia sin abandonar el asiento. El sistema asigna automáticamente el pedido al vendedor adecuado y optimiza su recorrido.

### Movilidad Inteligente

Recomienda la mejor puerta de ingreso y salida para reducir congestiones, utilizando información operativa disponible y reglas de recomendación.

## Tecnologías previstas

- Flutter
- NestJS
- PostgreSQL
- Redis
- Firebase
- Gemini API

## Principios

- Arquitectura modular.
- Escalabilidad.
- Desarrollo incremental mediante MVP.
- La IA actúa como orquestador, no como reemplazo de la lógica de negocio.
- Experiencia del usuario como prioridad.
